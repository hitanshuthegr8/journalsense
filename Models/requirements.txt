# Pinned to the exact versions this project is developed and tested against.
# Unpinned dependencies mean "whatever resolved the day you installed", which makes a
# benchmark result impossible to reproduce and a container impossible to rebuild.
#
# Verified against Python 3.12.
#
# Changes from the previous unpinned list:
#   - removed  spacy + en_core_web_sm : the pin was a 2.x model against a 3.x runtime, so
#              it never loaded. Its only consumer (extract_key_phrases, display-only) now
#              uses scikit-learn instead. This also removes a runtime `spacy download`
#              subprocess that could not work inside a container.
#   - removed  altair : declared but not imported anywhere in the codebase.
#   - added    matplotlib : imported by keywordFinder.py but never declared. It resolved
#              only as a transitive dependency of wordcloud, which is luck, not a contract.
#   - bumped   scikit-learn 1.3.2 -> 1.7.2 : 1.3.2 is compiled against the numpy 1.x C
#              ABI and raises "numpy.dtype size changed" on import under numpy 2.x. With
#              numpy 2.4.4 installed, sklearn could not be imported at all - which meant
#              keywordFinder.py AND Models/eval/bench.py were both unrunnable. Verified
#              1.7.2 + numpy 2.4.4 imports and vectorises correctly.
